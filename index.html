In List Settings → Advanced Settings, enable Attachments for file uploads.
STEP 2 Set Entra ID permissions (Microsoft login)
Go to List Settings → Permissions → Break permission inheritance
• IAD Admin group (your team) → Full Control
• Department PIC groups → Edit Items (filtered to their department via Item-Level Permissions)
• All staff → Read
Microsoft login is automatic — users sign in with their M365 account. No separate password needed.
STEP 3 Build 3 Power Automate flows
Flow A — Daily Overdue Check
Trigger: Recurrence → Every day at 08:00
Action: SharePoint – Get Items (AuditRegisterList)
  Filter: Status ne 'Closed' and Status ne 'Extended'
Condition: item[Deadline] < utcNow()
  YES → Update Item (Status = 'Overdue')
       Send email (Outlook) → Responsible Party + IAD Lead
       Subject: [OVERDUE] @{AuditTitle} – Action required
Flow B — Extension / Escalation Alert
Trigger: SharePoint – When item is modified
Condition: Status changed to 'Extended' OR 'Overdue'
  YES → Send email to IAD Lead + Dept Head
       Subject: [AUDIT UPDATE] @{AuditTitle} – Status @{Status}
       Body: Include new deadline, reason, remarks
Flow C — Excel Import to SharePoint List
Trigger: Manual / Button
Action: Get rows from Excel (OneDrive/SharePoint file)
Apply to each row:
  Condition: Status = 'Closed'
    YES → Create item (IsHistorical = Yes)
    NO  → Create item (IsHistorical = No) → triggers Flow B if Overdue
STEP 4 Connect this portal to SharePoint via Microsoft Graph API
Replace localStorage in this portal's data layer with Microsoft Graph calls:
// 1. Register an app in Azure AD (App registrations)
// Permissions: Sites.ReadWrite.All, Mail.Send

// 3. Read findings

  { headers: { Authorization: "Bearer " + token.accessToken } })

// 4. Create finding
